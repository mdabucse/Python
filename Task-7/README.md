#  Mini Language Compiler / Interpreter (Step-by-Step Build)

##  Project Goal

Build a **mini programming language** from scratch with:

* Lexer (Tokenization)
* Parser (AST Builder)
* Interpreter (Execution Engine)

---

#  Current Progress ✅

##  Completed

* Token Types (`token_types.py`)
* Lexer (Tokenization)
* Basic Parser (`let`, `print`)
* Basic Interpreter (variables + print)

---

# Architecture Overview

```text
Source Code
   ↓
Lexer (Tokens)
   ↓
Parser (AST)
   ↓
Interpreter (Execution)
   ↓
Output
```
